# sawakai_chat
茶話会_みんなで脳活

## 散歩の記録

散歩前や散歩中に外部の地図アプリを開いて道を選べます。選んだ経路は
散歩アプリへ取り込まれず、外部アプリに切り替えると端末によっては位置記録が
途切れます。位置情報を「経路も記録」に設定した場合、散歩後の記録から
経路を表示できます。地図画像の取得時には経路周辺の位置が地図サービスに送られます。

時間とGPSの点から計算した概算距離は同じ端末・ブラウザーに保存され、
記録の削除まで残ります。位置を記録しない場合や点が不足する場合、距離は
表示できません。位置取得のエラーや長い空白などが分かる場合は一部のみの
記録として表示し、途切れた区間は距離に含めません。GPSの誤差や検知できない
中断もあるため、距離の正確さは保証されません。以前の経路が残る記録も
概算できますが、取得状況が不明なため一部のみの記録として扱います。

経路は保存から7日経過後、アプリで記録を読み込んだとき、または表示中の
定期処理で削除されます。アプリを閉じている間に削除される保証はありません。
月の切り替えで過去の記録を確認でき、1日複数回の散歩も別々に保存されます。

## 位置共有

「参加者と招待」からグループごとに任意でオンにします。同じグループで
共有をオンにした人同士が、最新位置と更新時刻を一人ずつ外部地図で確認できます。
アプリが開いている間は約1時間ごとに更新し、翌日も再開します。ブラウザーが
閉じている間やスリープ中の更新は保証できません。

最新位置は日本時間23時59分以降は表示せず、データベースの定期処理が
期限切れ位置を削除します。位置の履歴は保持しません。障害時の削除遅延、
バックアップや外部地図での保持は別途考慮が必要です。共有をオフにすると
そのグループの位置が削除され、退出時にはこの端末の全グループの共有を停止します。
現在の参加方法は表示名の本人確認を行わないため、招待コードを知る人による
なりすましを防げません。緊急時の居場所確認には使えません。

運用時は `supabase/migrations/` の位置共有用マイグレーションを順に適用し、
`location-sharing` Edge Function をデプロイしてください。`pg_cron` の
`sawakai-location-daily-cleanup` が有効で、定期実行に失敗していないか監視します。
`supabase/tests/location_sharing.sql` はトランザクションをロールバックして
閲覧制限・参加者削除・期限切れ位置の削除を確認します。
